# 블루클럽 ERP 설치 파일

사업단의 재고와 거래를 관리하는 Windows 프로그램 '블루클럽 ERP'의 설치 파일을 받는 곳입니다.

## 받기

- [Blueclub-ERP-Setup-0.1.1.exe](https://github.com/hlog2e/blueclub-erp-download/releases/download/v0.1.1/Blueclub-ERP-Setup-0.1.1.exe) (Windows 10·11 64비트, 119MB)
- 지난 버전은 [Releases](https://github.com/hlog2e/blueclub-erp-download/releases)에 있습니다.

## 설치

1. 받은 파일을 더블클릭합니다. 'Windows의 PC 보호' 창이 뜨면 '추가 정보'를 누른 다음 '실행'을 누릅니다. 아직 서명을 붙이지 않은 설치 파일이라 Windows가 한 번 확인하는 창입니다.
2. 설치가 끝나면 프로그램이 바로 켜집니다. 관리자 권한을 묻지 않습니다. 바탕 화면과 시작 메뉴에 'Blueclub ERP' 바로 가기가 생깁니다.
3. 처음 화면에서 '이 PC를 메인 PC로 시작'을 선택합니다. 함께 쓸 다른 PC에는 같은 파일을 설치하고 '메인 PC에 연결'을 선택합니다.

## 새 버전으로 바꾸기

새 설치 파일을 메인 PC부터 실행하면 덮어 설치되고 자료는 그대로 남습니다.
